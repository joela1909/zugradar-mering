This skill guides the creation of premium, consumer-facing interfaces that embody the "Apple aesthetic"—an intersection of extreme technical precision and liberal arts. Implement real working code with an obsession for minimalism, readability, and confident presentation.

The user provides frontend requirements: a product, feature, or interface to showcase. They may include context about the core value proposition.

## Design Thinking

Before coding, internalize the Apple design philosophy and commit to a purely essentialist direction:
- **Purpose**: The product or the core message is the absolute hero. The interface should disappear.
- **Tone**: Confident, restrained, premium, breathless, and intensely focused. 
- **Differentiation**: "Less, but better." Achieve the unmistakable feeling of a high-end product launch. The power of a single, perfectly centered statement with massive negative space.
- **Constraints**: Flawless responsiveness, meticulous alignment, and semantic structure.

**CRITICAL**: Elegance comes from what you choose to remove, not what you add. Every pixel, shadow, and word must rigorously justify its existence. 

## Frontend Aesthetics Guidelines

Focus heavily on:
- **Typography**: This is the absolute core of Apple's design. ALWAYS prioritize the system font stack (San Francisco, `-apple-system`, `BlinkMacSystemFont`, `SF Pro Display`). Use massive, heavy weights (`700`, `800`) with tight tracking (`letter-spacing: -0.01em` to `-0.05em`) for primary headlines. Pair with subdued, perfectly legible secondary text (regular weight, `#86868b`).
- **Color & Theme**: Practice extreme restraint. Use a monochromatic base: absolute white (`#ffffff`) or warm off-white (`#fbfbfd`) for light mode; deep, rich blacks (`#000000` or `#1d1d1f`) for dark mode. Text is rarely pure black. Use "Apple Blue" (`#0066cc` to `#2997ff`) strictly for interactive links and primary buttons.
- **Motion & Interaction**: Silky, physical, and subtle. Avoid bouncy or frantic animations. Think smooth `ease-in-out` transitions, refined opacity fades, and scroll-linked reveals that feel grounded in real-world physics. Interactions should feel "heavy" and premium.
- **Spatial Composition**: Use generous, almost aggressive whitespace (negative space). Default to center-aligned hero sections with immense breathing room. For feature details, utilize asymmetric but perfectly balanced bento-box layouts or alternating left-right image/text blocks.
- **Copywriting**: Confident. Short. Punctuated. (e.g., "Pro cameras. Pro display. Pro performance." or "Light. Speed.") Convert the user's input into brief, impactful statements. Use periods to force a pause.
- **Visual Details**: Utilize modern iOS/macOS visual cues sparingly: subtle glassmorphism (`backdrop-filter: blur`), incredibly soft and expansive drop shadows to create z-axis depth, and precise `border-radius` to simulate smooth squircles.

NEVER use cluttered layouts, multiple competing primary colors, harsh/cheap gradients, playful/bouncy UI frameworks, or generic decorative shapes. NEVER use complex technical jargon in user-facing copy; translate technical features into human, benefit-driven emotions.

**IMPORTANT**: A true Apple-style interface requires intense attention to the micro-details. The spacing between a headline and a subheadline, the exact shade of grey for a border, and the contrast ratio must be perfectly tuned. 

Remember: You are designing for the world's most valuable brand. Don't add decoration; reveal the essence of the product. Show what can be created when you combine absolute minimalism with uncompromising execution.
